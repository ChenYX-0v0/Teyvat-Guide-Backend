## 1. 项目概况

「AI 提瓦特向导」（teyvatGuide）是一个面向 C 端用户的《原神》智能助手工具站：

| 项 | 说明 |
| --- | --- |
| 技术栈 | Go Gin + React SPA + GORM + MySQL（独立库 `teyvat_guide`） |
| 鉴权 | C 端 JWT；管理接口用 `X-Admin-Key` 静态密钥 |
| 已有管理 API | `POST /api/admin/assets/import`、`GET /api/admin/assets/missing`、`POST /api/admin/assets/reload` |
| 健康检查 | `GET /api/health`，返回 `{ status, version, time }` |
| 部署形态 | 独立 Go 进程，默认 `http://localhost:8080` |

## 2. 接入方式

按总体设计走**服务端网关代理**：

```
本系统页面 → /api/gateway/teyvat-guide/* → http://127.0.0.1:8080/api/admin/*
                                          （服务端注入 X-Admin-Key）
```

- 注册表配置：`code = "teyvat-guide"`，`auth_type = "header-key"`，`auth_config` 存 X-Admin-Key（当前取该项目 `config.yaml` 的 `auth.jwt_secret`）。
- 本系统浏览器侧只携带自身 Session，X-Admin-Key 不出服务端。
- 该项目无需配置 CORS。

## 3. 功能模块设计

### 3.1 第一期（现有接口即可支撑）

| 模块 | 对接接口 | UI 设计 |
| --- | --- | --- |
| 服务状态 | `GET /api/health` | 项目卡片：在线/离线状态、版本号；侧边栏菜单项带状态小圆点 |
| 翻译缺漏清单 | `GET /api/admin/assets/missing?limit=100` | 表格：kind（character/weapon/relic_set/text/prop）、asset_id、hit_count、first_seen；按命中数倒序；支持一键复制待补录 ID |
| 映射数据导入 | `POST /api/admin/assets/import` | 按 8 张映射表分组（characters / weapons / relicSets / textMap / propMap / fightProps / affixes / statWeights）的 JSON 上传或粘贴框；导入后展示各表 upsert 条数统计 |
| 内存映射刷新 | `POST /api/admin/assets/reload` | 「刷新内存」按钮 + 结果提示；导入成功后自动触发，无需重复操作 |

注意：修改映射数据后需 reload 生效，并清空该项目的 `asset_player_profile_snapshots`（旧快照不含新翻译）。

### 3.2 第二期（需 teyvatGuide 侧补管理接口）

| 模块 | 需新增接口 | 用途 |
| --- | --- | --- |
| 用户管理 | `/api/admin/users`（列表/封禁） | 查看 C 端用户、封禁账号 |
| 对话数据查看 | `/api/admin/chats`（会话/消息查询） | 审计对话内容、统计 Token 用量 |
| UID 绑定管理 | `/api/admin/bindings`（查询/解绑） | 管理用户 ↔ 游戏 UID 绑定关系 |
| 运行概览 | `/api/admin/stats` | 今日问答量、Token 消耗、快照缓存命中率 |

以上接口由 teyvatGuide 侧按其「新增接口五步法」分层规范实现。

## 4. teyvatGuide 侧需要的配合

1. **鉴权升级（建议）**：管理接口当前复用 `auth.jwt_secret` 作为 X-Admin-Key，建议升级为独立的 admin token，与 JWT secret 解耦。
2. **二期管理接口**：按上表补充 users / chats / bindings / stats 四组管理 API。
3. **无需 CORS**：走服务端代理后浏览器不直连 Go 服务。

## 5. 前端页面与路由规划（本系统侧）

```
src/app/admin/
├─ AdminShell.tsx              # 菜单新增「项目接入」分组
├─ teyvat-guide/
│  ├─ ServiceStatusPanel.tsx   # 服务状态
│  ├─ MissingAssetsPanel.tsx   # 翻译缺漏清单
│  └─ AssetImportPanel.tsx     # 映射数据导入
src/app/api/gateway/
└─ [project]/route.ts          # 统一网关代理
```

## 6. 响应体归一化

teyvatGuide 统一响应 `{ code, message, data }`（`code === 0` 成功），与本系统现有 `success/message` 风格不同，由网关层完成转换：

| teyvatGuide | 网关输出 |
| --- | --- |
| code = 0 | `{ success: true, data }` |
| code = 400 | `{ success: false, message: "参数错误" }` |
| code = 404 | `{ success: false, message: "资源不存在" }` |
| code = 502 / 503 | `{ success: false, message: "上游服务异常，请稍后重试" }` |
| 网络不可达 | `{ success: false, message: "teyvatGuide 服务不可达" }` |
